RAMAYANA: THE EPIC WORLD — MOBILE STARTER

This is a small playable starter prototype, not the complete finished game.

Included:
- Low-poly forest clearing and ground
- Temporary capsule character (placeholder for Shri Ram)
- Third-person camera
- On-screen left joystick for movement
- Right-side look control by dragging
- RUN and JUMP touch zones
- Keyboard fallback: WASD/arrows and Space

HOW TO OPEN:
1. Extract this ZIP into a folder.
2. Open Godot 4.x.
3. Choose Import and select project.godot from the extracted folder.
4. Open the project and press Play.

IMPORTANT:
The complete Ramayana story, authentic character models, Hindi voice acting, quests, combat, inventory, save system and large open world are not included yet. These need to be built and tested in stages. This starter is intentionally simple for low-memory phones.
